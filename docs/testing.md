# Ручная проверка перед релизом

Автоматически проверяются расписание перерывов, учёт программ, настройки и переводы (`npm test`), а CI собирает
приложение на macOS, Windows и Linux. Всё, что зависит от конкретной системы (окна поверх всех, трей, созвоны,
«Не беспокоить»), проверяется руками по этому списку.

## Где проверять

- **macOS:** на своём Mac, `UNSLOUCH_FAST=1 npm run tauri dev`. Минута в настройках идёт за 5 секунд.
- **Windows:** UTM (бесплатно, https://mac.getutm.app) + Windows 11 ARM. x64-сборку Windows на ARM запускает
  через эмуляцию. Установщик брать из артефактов CI или черновика релиза.
- **Linux:** UTM + Ubuntu 24.04 (GNOME; на экране входа можно выбрать сеанс Wayland или Xorg) и Fedora KDE (Wayland).

## Сценарии

Для каждой системы:

1. Установка.
   - Windows: SmartScreen → «Подробнее» → «Выполнить в любом случае».
   - macOS: открывается без предупреждений (подписано и нотаризовано: `spctl -a -vv Unslouch.app` → `Notarized Developer ID`).
   - Linux: AppImage запускается после `chmod +x`, .deb ставится через `sudo apt install ./файл.deb`.
2. Первый запуск: открывается окно «Засиделся работает», три шага, в конце настройки.
3. Иконка в трее или строке меню. На Windows при тёмной панели задач иконка белая, при светлой зелёная.
   В GNOME без расширения AppIndicator иконки нет, повторный запуск приложения открывает настройки.
4. Микропауза: экран закрывается на всех мониторах, есть упражнение, потом «Посмотрите вдаль», в конце звук.
   Кнопки «Отложить» и «Пропустить» работают, в статистике это видно.
5. Перерыв «встать»: упражнения для спины и ног, потом ходьба с отсчётом.
6. Сигнал «моргнуть»: края экрана темнеют на секунду, клики проходят сквозь окно, фокус не уходит из текущей
   программы (печатать в редакторе не мешает).
   На Wayland вместо этого системное уведомление.
7. Сигнал «сменить позу» и карточка воды. «Выпил» срабатывает с первого клика, карточка исчезает сама через 15 секунд.
8. Созвон: включить камеру или микрофон в другой программе (FaceTime, Zoom, Telegram), в трее
   «Созвон, напоминания ждут». После выключения перерыв приходит.
9. Видео на весь экран (YouTube в браузере): перерыв ждёт до 10 минут. На Wayland это не работает, так и задумано.
10. «Не беспокоить».
    - Windows 11: включить в центре уведомлений.
    - macOS: включить «Фокус». Если не сработало, это ожидаемо: Mac не всегда даёт прочитать режим.
11. Фокус 25 минут из трея: всё молчит, в конце сразу перерыв «встать».
12. Рабочее время: поставить конец через 2 минуты, в трее «Нерабочее время», напоминания молчат.
13. Время по программам: переключаться между двумя-тремя программами пару минут, во вкладке «Программы» они видны.
    На Wayland пункт недоступен с объяснением.
14. Отойти от компьютера на время из настройки «Отошёл от компьютера»: таймер перерыва сбрасывается.
15. Тёмная и светлая тема: переключение в настройках, окно меняется сразу.
16. Язык: переключить на два-три языка, меню трея меняется сразу. Проверить армянский и грузинский шрифт.
17. Экспорт в файл и импорт на другой системе: настройки и статистика переезжают.
18. Автозапуск: перезагрузить систему, приложение стартует само.
19. Обновление: выпустить x.y.z+1, в трее появляется «Установить версию …». После нажатия приложение обновляется
    и перезапускается. Без нажатия ничего не скачивается.
